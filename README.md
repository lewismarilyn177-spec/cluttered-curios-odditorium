Cluttered Curios: Night at the Odditorium — a spot-the-difference game with five hand-drawn lamp-lit museum scenes. Click differences, race the timer, use hints, build streaks. Procedural WebAudio.

**Run:** `node serve.ts` (or any static server over `game/`)  
**Build:** `MAKEFUN_OUTPUT_DIR=out node main.ts`  
**Controls:** Click/tap differences — H for hint — P to pause
